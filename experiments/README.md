# Sofascore v2.0 — отдельно устанавливаемый тест

**Не является проверенным исправлением мерцания.** Установите только при отключённых предыдущих Sofascore тестах и обновлённой странице.

Файлы:
- `sofascore-v2.0.css`: CSS для основного открытого Shadow DOM.
- `sofascore-v2.0.user.js`: экспериментальный загрузчик Violentmonkey с `@resource`.

Установка: https://raw.githubusercontent.com/blatokomitet/bcgame-design/main/experiments/sofascore-v2.0.user.js

В Violentmonkey ресурс CSS загружается при установке/обновлении скрипта. Если меняется только CSS, обновите скрипт и повысьте его версию перед проверкой.

Цель: не менять inline-стили цифр на каждом LIVE-обновлении. Однако прошлые CSS-тесты показывали 11px вместо 42px, поэтому **не обещаем**, что CSS-only обеспечит 21px. Проверяйте `bcSofaV20Diagnostics()` в консоли userscript; при необходимости можно временно остановить через `bcSofaV20Stop()`. Перезагрузка страницы полностью отключает сеансовый эффект при выключенном userscript.

Оригинальные эмблемы, ссылки и LIVE-данные не изменяются напрямую. Селекторы `sc-*` зависят от текущей разметки сайта. Тестирование прематча пока не выполнено. Основные `bcgame.user.css`, `bcgame.user.js` и архив v1.9 не изменяются.
