# Sofascore Compact v2.9 — эксперимент

Отдельная версия, не затрагивающая v2.8 и основной загрузчик.

Изменения относительно v2.8: строки команды и счёта по 36 px; линия на границе двух строк (36 px) заканчивается перед правой областью счёта с отступом около 12 px; зелёный левый разделитель 3 px; время по центру слева; лига над карточкой. Размер и цвет счёта сохранены из v2.8 (белый, без плашки, CSS transform). Не меняет оригинальные эмблемы и ссылки, скрывает коэффициенты.

ВНИМАНИЕ: расположение и фактическая высота требуют проверки. Зависимость от динамических классов сайта сохраняется.

Для установки отключить v2.8 и другие Sofascore userscripts, очистить временные тесты Eruda обновлением страницы, затем установить https://raw.githubusercontent.com/blatokomitet/bcgame-design/main/experiments/sofascore-v2.9.user.js и обновить страницу. Для отката отключить v2.9, включить v2.8 и обновить.
