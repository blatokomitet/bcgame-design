# Sofascore Compact v2.8 (эксперимент)

Отдельная сборка. НЕ менять и НЕ включать одновременно с v2.2, v2.1 или тестами Eruda.

- Лига визуально над фоном карточки, без общей рамки.
- Только время слева, зелёный вертикальный разделитель 3 px.
- Команды в двух строках по 40 px.
- Белый счёт справа, визуально около 17px через scale(1.54545), без плашек.
- Горизонтальный разделитель проходит под командами и счётом по границе между двумя строками.
- Коэффициенты и избранное скрыты.
- Оригинальные ссылки, эмблемы и данные сохранены.
- CSS не меняет inline font-size; LIVE и prematch нужно проверить на реальных карточках.

Установка после согласования: https://raw.githubusercontent.com/blatokomitet/bcgame-design/main/experiments/sofascore-v2.8.user.js
После установки выключить другие Sofascore userscripts и обновить страницу. Для отката выключить v2.8, включить v2.2, обновить страницу.

Внимание: названия классов sc-* динамические, размещение времени использует текстовую метку, обновляемую на DOM-изменениях. Текущая высота 110–125 px — цель, а не гарантированный результат. Внешние закреплённые кнопки BC.GAME не меняются.
