# Sofascore Compact v2.2 — отдельный тест

**Статус: готов к тестированию, НЕ установлен, НЕ согласован.**

Цель — более плотные карточки ориентировочно **110–125 px**, с оригинальными эмблемами, названиями, прематч/LIVE и ссылками. Большой блок коэффициентов и избранное скрываются по наблюдавшейся разметке BC.GAME. Счёт сохраняет стабильный визуальный `transform: scale(1.90909)` из v2.1 без переписывания inline-стилей. Цвет `#20d982`.

Файлы:
- `sofascore-v2.2.css` — вся компоновка и оформление
- `sofascore-v2.2.user.js` — отдельный загрузчик CSS в Shadow DOM

**Установленная v2.1 и основные `bcgame.user.js`/`bcgame.user.css` не изменены.**

Новая группа лиг вынесенная за пределы отдельных карточек пока НЕ реализована: такой перенос потребовал бы изменять DOM и мог бы повредить обновления матчей. Вместо этого заголовок лиги компактно оставлен в каждой карточке.

Проверка: сначала отключить v2.1 в Violentmonkey; затем установить v2.2 по адресу:
https://raw.githubusercontent.com/blatokomitet/bcgame-design/main/experiments/sofascore-v2.2.user.js

После включения обновить страницу. Сравнить высоту 5–8 карточек, равномерность расположения двух цифр счёта, мерцание и прематч. Целевые 110–125 px не гарантируются на всех карточках: текст лиг/команд может переноситься и сайт может обновить структуру.

Важный нюанс: `@resource` кэшируется расширением и CSS не обязательно обновляется при каждой правке в GitHub. Для теста следующей версии обновить userscript с повышением `@version` и перезагрузить страницу.

Откат: выключить v2.2, включить сохранённую v2.1, обновить страницу. Не запускать обе версии одновременно.
