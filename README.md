# BC.GAME Design

Исходники экспериментального оформления BC.GAME для Stylus и Violentmonkey.

## Установка через GitHub Raw (после публикации репозитория)

- Stylus: https://raw.githubusercontent.com/blatokomitet/bcgame-design/main/bcgame.user.css
- Violentmonkey: https://raw.githubusercontent.com/blatokomitet/bcgame-design/main/bcgame.user.js

Откройте Raw-URL каждого файла в браузере с установленным расширением и подтвердите установку. В Stylus включите **Check for updates**; в Violentmonkey включите обновления скриптов. Версии повышаются через `@version`. Обновления периодические; для быстрой проверки их нужно запускать вручную и затем перезагрузить страницу.

**Удалите или отключите старые вручную созданные копии этих же файлов**, чтобы не получить два одинаковых скрипта/стиля. Перед включением новой версии отключите временные тесты Eruda, обновив страницу.

## Статус

Основные файлы `bcgame.user.css` и `bcgame.user.js` — **безопасные заготовки версии 0.2.0**. Они ещё не применяют Sofascore дизайн и не изменяют страницу.

- `backups/sofascore-v1.9-eruda.js` — архив временного теста с известным мерцанием; **не устанавливать как постоянный userscript**.
- Рабочая страница: `https://bcgame.st/ru/sports/live`.
- Спортивные карточки находятся внутри открытого Shadow DOM; Stylus самостоятельно не достигает его потомков.
- Для оформления карточек потребуется Violentmonkey-загрузчик, внедряющий CSS внутрь соответствующего Shadow DOM.
- Существующие постоянные скрипты не менялись.

## Безопасность публикации

Перевод в Public раскрывает текущие файлы, историю коммитов и резервную копию теста v1.9. Не храните токены, пароли, cookie и приватные данные в репозитории. Настройку видимости выполняет владелец в Settings → Danger Zone → Change repository visibility.
