# BC.GAME Design

Отдельный тестовый проект для интерфейса BC.GAME.

- **bcgame.user.css** — безопасная заготовка стилей Stylus для обычного DOM.
- **bcgame.user.js** — безопасная заготовка скрипта Violentmonkey, без изменений на странице.

## Текущий статус
Оба файла — шаблоны без активных изменений дизайна. Существующие постоянные скрипты не затронуты.

## Важно: приватный репозиторий
GitHub Raw для приватного репозитория требует авторизации. Прямая установка или автообновление из обычной raw-ссылки в Stylus/Violentmonkey **может не работать**. Для первичного тестирования можно вручную скопировать содержимое файлов в расширения. Для надёжных автоматических обновлений потребуется доступный по HTTPS источник (например, отдельный публичный репозиторий только с несекретным кодом).
