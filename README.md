# BC.GAME Design

Пользовательские скрипты оформления BC.GAME и отдельный мобильный стенд. Это не самостоятельный клиент BC.GAME: на настоящем сайте оформление зависит от его DOM и открытого Shadow DOM.

## Быстрый запуск предпросмотра

Нужен Node.js 22 или новее. Зависимости нужны только для тестов; сам сервер работает на стандартной библиотеке Node.js.

```sh
npm ci
npm run dev
```

Откройте `http://localhost:4173`. При сохранении HTML, CSS и JS страница автоматически перезагружается. Сервер слушает `0.0.0.0`, поэтому его можно открыть через предпросмотр облачной среды. Порт задаётся переменной `PORT` (по умолчанию 4173).

### Работа с телефона

1. Откройте нужную ветку репозитория в GitHub Codespaces или импортируйте её в Replit.
2. В терминале выполните команды выше.
3. Откройте веб-предпросмотр порта 4173; в облачной среде используйте её выданный HTTPS-адрес, а не localhost телефона.
4. Поручите агенту изменить файлы. Открытый предпросмотр обновится после сохранения. Если прокси среды не пропускает EventSource, обновите страницу вручную.
5. Проверьте сценарии «Гол», «Прематч», «Нет матчей», «Ошибка данных», «Новый раздел» и отключение дизайна.

Стенд использует реальные userscript-файлы шапки, темы и карточек, но синтетические матчи и упрощённую исходную разметку. Авторизация, деньги, купон и сетевые данные BC.GAME не подключаются. Кнопки аккаунта и нижней панели демонстрационные. Успешная проверка стенда не доказывает совместимость с текущей разметкой BC.GAME.

## Текущие компоненты

| Файл | Версия | Назначение |
|---|---|---|
| `bcgame.user.js` | 0.4.0 | Мобильная шапка, повторная активация при замене DOM, откат при изменении ширины, Escape в меню |
| `bcgame-calm-dark.user.js` | 1.3.0 | Тёмная тема и компактная нижняя панель; восстановление геометрии от 600 px |

| `BCGAME_Chrome_Design_v1.9.user.js` | 1.9.1 | Альтернативная нижняя панель, checkpoint; фактическое нажатие купона требует проверки |

## Совместимость

Рекомендуемый тестовый комплект: **Minimal Header + Calm Dark + Match Cards 2.6.0**.

- **Calm Dark и Chrome Dock нельзя включать одновременно.** Теперь первый запущенный скрипт блокирует запуск второго; выбор отражается предупреждением в консоли. Для смены варианта отключите старый и перезагрузите страницу.
- Выбирайте только **одну** реализацию карточек: Match Cards или один Sofascore из `experiments/`.
- Не запускайте архивы и старые Eruda-тесты поверх текущего комплекта.
- Перестройка шапки ограничена шириной 360–599 px. Если геометрия не проходит проверку, остаётся оригинальная шапка.
- Карточки 2.6.0 поддерживают ссылки того же сайта с `/sports/soccer/`. Другие виды спорта и неизвестная структура остаются оригинальными.
- Прематч без счёта поддерживается при наличии времени `HH:MM`. Другие неоднозначные состояния сохраняют оригинальное представление.

## Установка на настоящем сайте

Откройте Raw-файл выбранного `.user.js` в браузере с userscript-менеджером. Отключите старые копии и конфликтующие варианты, затем перезагрузите страницу.

Для изменений в pull request используйте Raw именно его ветки. **Не устанавливайте экспериментальную ветку в качестве постоянного комплекта до проверки.** У основного скрипта шапки и Calm Dark `@updateURL` указывает на main: тестовую копию лучше устанавливать без автообновления, иначе менеджер может позднее заменить её версией main. После принятия изменений переустановите стабильные Raw-файлы из main.

Изменение файла на GitHub не меняет уже открытый BC.GAME мгновенно: нужно обновить установленный скрипт и страницу. Для `@resource` CSS кэшируется менеджером, поэтому меняйте версию загрузчика при выпуске CSS. Живое обновление в этой версии реализовано для отдельного стенда.

## Проверки

```sh
npm run check
npm test
npx playwright install chromium
npm run test:browser
```

- `check`: синтаксис JavaScript, включая архивные файлы.
- `test`: 16 DOM-регрессий на Happy DOM; геометрические проверки используют моделируемые размеры.
- `test:browser`: настоящий Chromium, ширины 320/360/390/430/800 px, меню, сценарии данных, откат, reduced motion, отсутствие горизонтального переполнения и закрытые пути сервера.
- GitHub Actions выполняет обе группы тестов. Скриншот браузерной проверки сохраняется локально в `test-results/`.

## Ручная приёмка на BC.GAME

1. Вход и выход, переходы между страницами, замена шапки.
2. LIVE, добавленное время, прематч, перерыв, завершённый матч, неподдерживаемая карточка.
3. Сравнение счёта и времени с оригиналом после отключения оформления.
4. Ориентация экрана и изменение размеров; большие названия команд и баланс.
5. Открытие матча, исходные кнопки уведомлений, подарков и купона.
6. Прокрутка длительной ленты, повторная загрузка и полный откат.

## Быстрый откат в консоли страницы

```js
window.__bcMatchCardsV014?.disable();
window.__bcMinimalHeaderV21?.restore();
window.__bcCalmDarkFourColorsV100?.restore();
window.bcChromeV19CheckpointDestroy?.();
```

Для постоянного отключения выключите скрипт в менеджере и обновите страницу. Команды доступны в том контексте, где менеджер выполняет скрипт.

## Ограничения и безопасность

Оформление по-прежнему зависит от селекторов внешнего сайта. При нераспознанных данных показывается оригинальная карточка. Закрытый Shadow DOM не поддерживается. Логотипы переносятся только как безопасные HTTP(S)-изображения; произвольный SVG/HTML не копируется. Неподдерживаемый SVG заменяется буквой команды или нейтральным знаком. Декоративный колокольчик из новых карточек удалён, поскольку функции уведомлений у него не было.

В разработке используются отдельные файлы CSS/JS и стандартный Node-сервер. Сервер не предназначен для production или размещения секретов: он раздаёт только preview и три скрипта, необходимые стенду.

Архивы находятся в `backups/`, старые альтернативы — в `experiments/`. Архивный загрузчик 2.9 привязан к CSS конкретного коммита; ссылки автоматического перехода на текущую версию удалены.
