# Sofascore v1.9 — резервная копия теста

Дата: 2026-10-12. Источник: код, ранее запущенный через Eruda в разговоре.

**Файл:** `sofascore-v1.9-eruda.js` — восстановленный текст временного теста. Это архивный снимок, **не подтверждённая стабильная версия**. Не подключайте его как постоянный userscript без проверки.

## Наблюдавшийся вид на скриншоте

- Счёт: **21 px**, зелёный `#20d982`, расположен справа
- Оригинальные логотипы команд и ссылки оставлены
- Коэффициенты и звёздочки скрыты с помощью селекторов текущей разметки
- LIVE отображается; стиль иногда **мигает при прокрутке/перерисовке карточек**
- Плавающие кнопки сайта могут перекрывать карточки

## Ограничения

- v1.9 меняет `font-size` через inline-стили и MutationObserver.
- Использует динамические CSS-классы `sc-*`, которые могут меняться.
- Не воспроизводит *всю* последовательность старых тестов v1.4–v1.8; визуально идентичный результат не гарантирован.
- Для чистого теста рекомендуется новая загрузка страницы и отсутствие других активных тестов.
- Основные `bcgame.user.css` и `bcgame.user.js` **не изменены**.
- Приватный GitHub не гарантирует доступность Raw-URL расширениям без аутентификации.
